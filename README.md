# Codex Cloud skills

41 пользовательский навык находится в корневом каталоге [.agents/skills](.agents/skills).

Для следующей задачи Codex Cloud выберите этот репозиторий и ветку
`codex/migrate-cloud-skills`. После включения PR в `main` выбирайте `main`
или созданную от неё ветку. Навыки принадлежат репозиторию: они не устанавливаются
глобально для всех проектов и не добавляют доступ к внешним аккаунтам.

Пример запроса в новой задаче:

> Используй навык ru-writing-and-hiring. Отредактируй: «В целях своевременного
> закрытия периода просим осуществить оплату счёта № 17 на 12 000 ₽».

Подробные статусы всех навыков, необходимые программы и подключения, исправления,
проверка приватных данных и результаты пробного применения описаны в
[SKILLS-MIGRATION.md](SKILLS-MIGRATION.md).
32 навыка готовы к пробному использованию базового сценария;
9 требуют настройки зависимостей. Подключения CRM, почты, Figma и NotebookLM
требуют отдельной настройки и авторизации.

Проверка файлов (стандартная библиотека Python):

```bash
python3 tools/validate_cloud_skills.py
```

Проверка обнаружения установленным Codex CLI без запуска модели:

```bash
python3 tools/check_skill_discovery.py
```

Codex CLI должен иметь возможность записывать служебные метаданные. В защищённом
Cloud-контейнере для второй команды может потребоваться разрешённый запуск вне
файловой песочницы. Файлы `migration/discovery.json` и `migration/validation.json`
содержат результат проверки текущей среды; для новой среды проверку повторяют.
