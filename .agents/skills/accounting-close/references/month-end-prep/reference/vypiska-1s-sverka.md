# Выписка и 1С — справочник по сверке

## Что выгружаем

### Отчёт о прибылях (P&L) — из 1С

Данные по выручке, себестоимости, валовой прибыли и марже, операционным
расходам и чистой прибыли за целевой месяц. Берите из отчёта в 1С («Отчёт о
прибылях и убытках» / «Финансовый результат») или из сводного файла
(`1с_продажи.csv` + `расходы.csv`), если прямого коннектора нет.

Ключевые поля, которые используются дальше:

| Поле | Заметки |
|---|---|
| Выручка (итого) | Верхняя строка |
| Себестоимость (COGS) | Прямые затраты на товар/услугу |
| Валовая прибыль | Выручка минус себестоимость |
| Валовая маржа % | Валовая прибыль ÷ выручка |
| Чистая прибыль | Итоговая строка |
| Операционные расходы | Сумма текущих расходов |

Названия полей и колонок в вашей выгрузке 1С могут отличаться — ищите по
смыслу (сумма, дата, статья, контрагент), не требуйте точную схему.

### Регистр операций — банковская выписка + 1С

Возьмите построчную детализацию за целевой месяц: банковскую выписку
(`выписка_банка.csv`) и/или регистр продаж и расходов из 1С. Это основа для
поиска неразнесённых операций и дублей.

Ключевые поля:

| Поле | Заметки |
|---|---|
| Дата операции | Дата операции, не дата проводки |
| Тип операции | Приход / расход, счёт, платёж и т.д. |
| Сумма | Положительная = приход, отрицательная = расход в большинстве выгрузок |
| Статья / категория | Категория учёта (аналог счёта в 1С) |
| Контрагент | Поставщик или клиент |
| Назначение платежа | Свободный текст из банковской выписки |
| Есть документ | Отметка, что чек/акт прикреплён |

## Как определять неразнесённые операции

Помечайте операцию как неразнесённую, если статья/категория:
- «Не определено» / «без категории»
- пусто / null
- «Уточнить у бухгалтера» (встроенная категория «пока не знаю, куда
  отнести»)

## Большие выгрузки

Если файл 1С или банковской выписки очень большой (десятки тысяч строк),
обрабатывайте его батчами по 500–1 000 строк за раз, чтобы не терять
контекст и не пропускать операции.

## Типичные проблемы данных

**Разбитые операции** — одна покупка, разнесённая по нескольким статьям в
1С, появляется как несколько строк с той же датой и контрагентом, но
разными суммами. Это НЕ дубли. Прежде чем флагать дубли, группируйте строки
по номеру документа/чека — строки с одним номером — это части одной
операции.

**Банковская выписка vs ручные проводки** — операции из банковской выписки
обычно имеют чёткое назначение платежа; ручные проводки в 1С часто без
комментария. Само по себе это не признак проблемы, но помогает объяснить,
почему у операции может не быть чека/акта.

**Поступления ЮKassa/эквайринга уже в 1С** — если настроена автовыгрузка,
операции ЮKassa/эквайринга уже будут в регистре 1С. Не считайте их дважды
при сверке (шаг 3). Проверьте, есть ли пометка «ЮKassa» или «эквайринг» в
счёте или комментарии строки, прежде чем сопоставлять.

**Предоплаты и авансы** — аванс клиента не является выручкой, пока услуга
не оказана или товар не отгружен. Если бизнес работает по кассовому методу,
это различие менее критично, но крупные операции с пометкой «аванс» или
«предоплата» без встречной реализации стоит вынести отдельно для внимания
владельца.
