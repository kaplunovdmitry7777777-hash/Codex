# Справочник по формату пакета закрытия

Пакет закрытия — это два файла: рабочая книга xlsx и однострочный
PDF-обзор.

## Имена файлов

```
close-packet-2024-03.xlsx
close-packet-2024-03-summary.pdf
```

Используйте формат ISO 8601 год-месяц (`YYYY-MM`) в имени файла. По
умолчанию сохраняем в рабочую папку бизнеса; используйте путь, который
укажет пользователь, если он есть.

---

## Рабочая книга xlsx — три листа

### Лист 1: Отчёт о прибылях

Отформатированная копия отчёта о прибылях из 1С за целевой месяц.
Двухколоночная раскладка: **Статья** и **Сумма**.

Обязательные строки (по порядку):
1. Промежуточный итог по выручке
2. Промежуточный итог по себестоимости
3. **Валовая прибыль** (жирным)
4. **Валовая маржа %** (жирным, формат %)
5. Операционные расходы по статьям (каждая на своей строке)
6. Итого операционных расходов
7. **Чистая прибыль** (жирным)

Добавьте колонку сравнения месяц к месяцу, если есть данные за прошлый
месяц. Форматируйте суммы как валюту (`# ##0,00 ₽`). Отрицательные
значения — красным.

### Лист 2: Сверка

Сопоставление прихода в банковской выписке против поступлений
ЮKassa/эквайринга.

Колонки:
| Колонка | Источник |
|---|---|
| Дата (выписка) | Дата прихода в банковской выписке |
| Сумма (выписка) | Сумма прихода в банковской выписке |
| Канал | ЮKassa / банковский эквайринг |
| Дата (канал) | Дата зачисления по данным канала |
| Сумма (канал) | Чистая сумма к зачислению |
| Дельта | Сумма по выписке минус сумма по каналу |
| Статус | СВЕРЕНО / НЕТ_В_ВЫПИСКЕ / ПРИХОД_БЕЗ_ИСТОЧНИКА / РАСХОЖДЕНИЕ_ПО_ДАТЕ |

Раскрасьте колонку «Статус»:
- СВЕРЕНО → заливка зелёным
- РАСХОЖДЕНИЕ_ПО_ДАТЕ → заливка жёлтым
- НЕТ_В_ВЫПИСКЕ или ПРИХОД_БЕЗ_ИСТОЧНИКА → заливка красным

### Лист 3: Задачи

Любые открытые флаги из чек-листа. Колонки:
| Колонка | Заметки |
|---|---|
| Категория | Неразнесённая операция / Нет чека-акта / Дубль / Флаг сверки |
| Дата | Дата операции |
| Сумма | Сумма в рублях |
| Контрагент | Поставщик или клиент |
| Описание | Что не так и что нужно сделать |

Если открытых задач нет, покажите одну строку: «Открытых задач нет — учёт
в порядке».

## PDF-обзор — одна страница

Раскладка (сверху вниз):

```
[Название бизнеса]                 Пакет закрытия — [Месяц Год]
────────────────────────────────────────────────────────────

КЛЮЧЕВЫЕ ЦИФРЫ
Выручка         XXX XXX ₽
Валовая маржа   XX%
Чистая прибыль  XXX XXX ₽

ОТЧЁТ О ПРИБЫЛЯХ
[150–250 слов простым языком из шага 7]

ЗАДАЧИ
X неразнесённых операций · X недостающих чеков/актов · X открытых флагов
[или «Учёт в порядке — открытых задач нет.», если всё чисто]

────────────────────────────────────────────────────────────
Подготовлено [Дата] · Собрано с ассистент
```

Используйте чистый рубленый шрифт (Helvetica или аналог). Логотип не
обязателен. Держите поля ≥ 1,9 см со всех сторон, чтобы страница нормально
печаталась.

**Генерация PDF:** используйте библиотеку Python `xlsxwriter` или
`reportlab`, если запускаете скрипт, либо попросите ассистент собрать контент
и выгрузить его через любой доступный инструмент печати в PDF.
Пользователь также может распечатать PDF прямо с листа «Отчёт о прибылях»
в xlsx, если скрипта под рукой нет.
