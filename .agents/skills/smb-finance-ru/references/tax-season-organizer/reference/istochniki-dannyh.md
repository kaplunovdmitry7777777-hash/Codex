# Как забирать данные из источников

Как правильно вытащить нужные данные из каждого источника для каждого режима.

---

## Банковская выписка — режим «Аванс по УСН» (доходы/расходы)

Возьмите выписку по расчётному счёту за период с начала года (или с начала
квартала — смотря что считаете) по последний закрытый день.

Ключевые поля:
- `Дата операции`
- `Сумма` (со знаком: приход/расход)
- `Назначение платежа`
- `Контрагент` (если есть в выписке)

Суммируйте все поступления как доходы. Для «доходы минус расходы» отдельно
суммируйте расходы, входящие в закрытый перечень УСН (ст. 346.16 НК РФ) —
если выписка не даёт понять природу расхода, пометьте как «уточнить у
бухгалтера», не относите к расходам по умолчанию.

**Если выписка в валюте, отличной от рублей** — уточните у пользователя курс
пересчёта или попросите рублёвую выписку.

---

## 1С — режим «Аванс по УСН» (доходы/расходы)

Если продажи и расходы ведутся в 1С, возьмите отчёт за тот же период.
Ключевые поля обычно называются:
- `Выручка` / `Продажи`
- `Расходы` / `Себестоимость`
- `Прибыль` (справочно — для УСН важна не бухгалтерская прибыль, а кассовая
  база, см. calculation-assumptions.md)

Если 1С и банковская выписка дают разные цифры (метод начисления против
кассового) — используйте кассовый метод (по выписке) для налогового расчёта
и отметьте расхождение в выводе.

---

## ЮKassa / эквайринг — режим «Аванс по УСН» (доходы) и «Документы по подрядчикам» (выплаты)

**Для доходов:** пулим все поступления от клиентов за период. Исключаем
возвраты клиентам — они уменьшают доход.

**Для выплат подрядчикам:** если через ЮKassa/эквайринг шли исходящие
выплаты физлицам/ИП (не только приём платежей от клиентов) — включите их в
свод по подрядчикам с пометкой источника «ЮKassa».

Ключевые поля обычно:
- `Дата`
- `Сумма`
- `Тип операции` (поступление / выплата / возврат)
- `Контрагент` / `Получатель`

---

## Банковская выписка / 1С — режим «Документы по подрядчикам»

Возьмите из выписки все исходящие платежи физлицам и ИП за услуги/работы за
нужный период (обычно год).

Фильтруйте по:
- Назначению платежа: «за услуги», «за работы», «оплата по договору ГПХ»,
  «оплата по договору оказания услуг»
- Исключайте: закупку товаров, возвраты, переводы между своими счетами

Для каждого получателя зафиксируйте:
- Имя / название (полное, по возможности — юридическое)
- Статус, если известен (самозанятый / ИП / физлицо без статуса / юрлицо)
- Сумма и дата каждого платежа
- Назначение платежа (для проверки, что это услуги, а не товары)

**Частая проблема:** не все выплаты в выписке помечены понятным назначением
платежа. Если по назначению нельзя понять, услуга это или нет — включите в
список с пометкой «уточнить», не исключайте молча.

## CSV-выгрузка напрямую (запасной вариант)

Если ни один коннектор не подключён, попросите пользователя выгрузить:
1. Выписку по счёту (обычно доступна в интернет-банке — «Экспорт» /
   «Выписка за период», CSV или Excel)
2. Отчёт по продажам/расходам из 1С
3. Реестр операций ЮKassa/эквайринга

При чтении загруженных CSV ищите такие колонки (названия отличаются в
зависимости от банка/сервиса):
- Выписка: `Дата`, `Сумма`, `Назначение платежа`, `Контрагент`
- 1С: `Дата`, `Сумма`, `Статья`, `Тип` (доход/расход)
- ЮKassa: `Дата`, `Сумма`, `Статус`, `Получатель/плательщик`, `ID операции`

Если колонки не совпадают — попросите пользователя указать, какая колонка
отвечает за получателя и сумму. Никогда не додумывайте соответствие колонок
молча.


Для подрядчиков веди реестр закрывающих и недостающих документов отдельно от расчёта УСН.
