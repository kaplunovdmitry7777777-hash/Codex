# Схема CSV-загрузки

Если у владельца нет под рукой живой выгрузки 1С или доступа к ЮKassa/эквайрингу, он может загрузить экспортированные CSV-файлы. В этом документе — какие столбцы ожидать и как обращаться с расхождениями.

## CSV выручки (выгрузка продаж/операций)

Ожидаемые столбцы (порядок не важен; заголовки регистронезависимы):

| Столбец | Обязателен | Описание |
|---|---|---|
| `date` / `дата` | Да | Дата операции (любой стандартный формат: ГГГГ-ММ-ДД, ДД.ММ.ГГГГ и т.д.) |
| `item` / `product` / `service` / `товар` / `услуга` / `описание` | Да | Что продано |
| `amount` / `revenue` / `сумма` / `итог` | Да | Сумма операции (₽) |
| `quantity` / `qty` / `количество` | Нет | Продано штук — если столбца нет, считать 1 на операцию |

**Выгрузки, которые обычно подходят под этот формат:**
- ЮKassa: Личный кабинет → История платежей → Экспорт (CSV)
- Эквайринг (банк-эквайер): Личный кабинет банка → Отчёт по операциям → Экспорт
- 1С: Отчёты → Продажи (или «Отчёт о продажах») → Выгрузить
- Кассовые/POS-системы (Эвотор, Штрих-М и подобные): Отчёты → Экспорт продаж

Если в выгрузке больше столбцов, чем нужно — лишние игнорировать. Если обязательного столбца нет — спросить владельца, какой столбец ему соответствует.

## CSV расходов/себестоимости

Ожидаемые столбцы:

| Столбец | Обязателен | Описание |
|---|---|---|
| `date` / `дата` | Нет | Дата расхода (пригодится для анализа тренда) |
| `item` / `product` / `service` / `category` / `товар` / `категория` | Да | К чему относится расход |
| `amount` / `cost` / `expense` / `сумма` / `расход` | Да | Сумма расхода (₽) |
| `type` / `тип` | Нет | Себестоимость vs операционный расход — если столбца нет, спросить владельца |

**Выгрузки, которые обычно подходят под этот формат:**
- 1С: Отчёты → Финансовый результат / расходы по статьям → Выгрузить
- Банковская выписка: интернет-банк → Выписка по счёту → Экспорт (CSV/XLSX)

## Что делать с неаккуратными CSV

Реальные выгрузки редко бывают чистыми. Частые проблемы:

- **Лишние строки в шапке:** пропускать строки, пока не найдётся та, что похожа на названия столбцов
- **Символы валюты и разделители тысяч:** убирать `₽`, `$`, пробелы и запятые из числовых полей перед разбором
- **Разделитель `;` вместо `,`:** выгрузки из 1С и Excel в РФ часто используют точку с запятой как разделитель столбцов — проверить первую строку файла перед разбором
- **Кодировка:** файл может быть в Windows-1251, а не в UTF-8 — если кириллица выглядит как «кракозябры», это первый признак
- **Отрицательные суммы (возвраты):** учитывать их — они уменьшают чистую выручку
- **Смешанные валюты:** отметить и спросить, какую валюту использовать; по умолчанию — ₽, если не ясно
- **«Брутто» vs «нетто»:** для выручки предпочтительна сумма нетто (после комиссии эквайера/площадки); если не ясно — спросить

## После загрузки

Подтвердить у владельца форму данных, прежде чем продолжать:
- «Я загрузил X операций с [дата] по [дата] по Y товарам/услугам. Всё верно?»
- Если период или количество позиций выглядят странно — попросить владельца перепроверить фильтры выгрузки.
