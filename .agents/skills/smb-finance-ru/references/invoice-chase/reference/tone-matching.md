# Соответствие тона

Логика оценки клиента и правила тона для навыка «Коллектор» (invoice-chase).

## Оценка клиента

Оцените клиента по истории платежей за последние 12 месяцев (по банковской
выписке / ЮKassa). Для оценки нужно минимум 3 счёта в истории; если счетов
меньше — по умолчанию ставьте `иногда-опаздывает`.

| Оценка | Критерий |
|---|---|
| `надёжный-плательщик` | Платил вовремя или раньше срока в ≥ 75% счетов |
| `иногда-опаздывает` | Платил с опозданием в 25–50% счетов, или на клиента меньше 3 счетов в истории |
| `хронический-должник` | Платил с опозданием более чем в 50% счетов |

«Вовремя» значит платёж получен не позже срока оплаты, указанного в счёте.

## Тон по оценке

| Оценка | Тон | Характер |
|---|---|---|
| `надёжный-плательщик` | Мягкий | Дружелюбный, исходит из презумпции недосмотра. Начинается с доброй воли. |
| `иногда-опаздывает` | Нейтральный | Деловой, без оценок. Просто факты и напоминание. |
| `хронический-должник` | Твёрдый | Прямой, называет срок. Без теплоты, но и без обвинений. |

## Тема письма

- Мягкий: `Небольшое напоминание: счёт №[N] на [сумма] ₽`
- Нейтральный: `Напоминаем: счёт №[N] — [сумма] ₽, срок прошёл`
- Твёрдый: `Просрочка: счёт №[N] — [сумма] ₽ (просрочка [X] дн.)`

## Структура письма (для любого тона)

Каждое напоминание содержит: номер(а) счёта, общую сумму к оплате, дату
выставления счёта, срок оплаты по договору, число дней просрочки и
реквизиты/ссылку для оплаты.

Дополнения по тону:
- **Мягкий**: одна фраза-снисхождение («понимаю, дела заедают» / «возможно,
  письмо просто затерялось»)
- **Нейтральный**: без добавок — только факты
- **Твёрдый**: одна фраза со сроком («просим оплатить до [дата]»)

Одно действие на письмо. Никогда не два.

## Правило объединения

Если у клиента несколько просроченных счетов — объедините их в одно письмо.
Перечислите каждый счёт (номер, сумма, срок оплаты), затем укажите общую
сумму. Используйте оценку клиента в целом, а не оценку по самому
просроченному из его счетов.
