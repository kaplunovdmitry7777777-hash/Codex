# Рабочая папка направления

Цель: чтобы каждый новый сеанс работы с ИИ по направлению (ремонты, закупки, ОТИЗ, СБ, качество, финансы и т. д.) начинался не с нуля. У агента должны быть правила, словарь, история решений и готовые процедуры.

## Когда применять

- «Настрой направление <X>», «заведи рабочую папку по <X>».
- «Запомни решение по <X>», «обнови MEMORY», «что мы решили по <X>» (если папка уже есть).
- «Проверь папку направления на противоречия».

## Структура папки

```
<Направление>/
├── AGENTS.md          # правила работы агента с направлением
├── MEMORY.md          # журнал решений: что, когда, почему, кто
├── .agents/skills/
│   └── <процедура>/SKILL.md   # типовые процедуры направления
├── scripts/           # вспомогательные скрипты (по мере появления)
├── data/              # выгрузки; в имени файла дата среза: ГГГГ-ММ-ДД
└── out/               # готовые отчёты
```

## Режим 1. Создание папки

1. **Интервью (не больше 6 вопросов, одним сообщением):**
   - Границы направления: что входит, что нет.
   - Ключевые объекты: агрегаты, категории, подразделения, контрагенты.
   - Источники данных: 1С, Excel-реестры, акты, журналы; как часто обновляются.
   - Типовые задачи, которые повторяются (3–5 штук).
   - Ответственные и кому идут отчёты.
   - Запреты: что нельзя делать, кому нельзя отправлять, конфиденциальность.
   Если пользователь отвечает «на твоё усмотрение» — заполни разумными значениями и пометь их `[проверить]`.
2. **AGENTS.md** — по шаблону ниже, не длиннее 2 страниц.
3. **MEMORY.md** — пустой журнал с заголовком таблицы и первой записью «Папка создана».
4. **skills/** — по одному каркасу SKILL.md на каждую типовую задачу из интервью (название, когда применять, входные данные, шаги, формат результата, проверки).
5. **Отчёт пользователю:** дерево созданных файлов и список пунктов `[проверить]`.

### Шаблон AGENTS.md

```markdown
# <Направление> — правила работы

## Границы
Входит: …  Не входит: …

## Словарь
| Термин / сокращение | Значение |

## Источники данных
| Источник | Что содержит | Обновление | Ответственный |

## Правила
- Цифры только из источников; каждая цифра — со ссылкой на файл и дату среза.
- При нехватке данных — остановиться и перечислить, чего не хватает.
- Ничего не отправлять и не публиковать без явного подтверждения.
- Перед работой прочитать MEMORY.md; не предлагать отклонённые варианты без новых фактов.
- Формат результата по умолчанию: вывод в 1–3 предложениях → таблица → риски → действия.

## Конфиденциальность
…

## Типовые процедуры
- .agents/skills/<процедура>/SKILL.md — когда применять
```

### Шаблон MEMORY.md

```markdown
# <Направление> — журнал решений

| Дата | Решение | Почему | Отклонённые варианты | Кто решил | Пересмотреть, если |
|---|---|---|---|---|---|
```

## Режим 2. Запись решения

1. Прочитать MEMORY.md.
2. Проверить, не противоречит ли новое решение прежним. Если противоречит — показать конфликт и спросить, какое действует.
3. Добавить строку: дата, суть, причина, отклонённые варианты, кто решил, условие пересмотра.
4. Если решение меняет правило работы — предложить правку AGENTS.md (показать diff, менять после подтверждения).

Поручения с исполнителями и сроками ведутся в навыке реестра решений (`metallurg-upravlenie:reestr-resheniy`), если он доступен. MEMORY.md хранит контекст для агента: что выбрано и почему.

## Режим 3. Ревизия папки

Проверить и выдать отчёт GREEN / YELLOW / RED по пунктам:
- противоречия между AGENTS.md, MEMORY.md и SKILL.md;
- дубли и устаревшие правила;
- выгрузки в data/ старше заявленной периодичности;
- скиллы без входных данных или формата результата;
- остались ли пункты `[проверить]`.
Ничего не исправлять без подтверждения: сначала список правок.

## Правила

- Язык — русский, деловой, коротко.
- Не выдумывать факты о предприятии: неизвестное помечать `[проверить]`.
- Не хранить в файлах пароли, персональные данные сверх необходимого, номера счетов и карт.
- Если связан компьютер пользователя — создавать файлы в его подключённой папке; иначе в рабочей среде и отдать файлами.

В ChatGPT перенеси правила в инструкции проекта. MEMORY.md здесь означает журнал решений в папке проекта.
