# Проверка MCP-сервера

Возьми синтетические записи и зафиксируй ожидаемые результаты. Проверь согласование протокола, список инструментов, JSON-схемы, read-only запросы, пустой результат, пагинацию, отказ по доступу, недопустимый ввод и ошибку источника. Мутации испытывай на отдельном тестовом ресурсе. Зафиксируй ID и итог до и после.

Подбери несколько типичных пользовательских запросов. Для каждого укажи разрешённый набор инструментов, ожидаемую цепочку, проверяемый ответ и недопустимые побочные действия. Проверь сначала клиентом MCP, затем выбранным OpenAI-хостом при наличии доступа. Для автоматизации используй поддерживаемую схему целевого клиента и храни ключи вне набора. В отчёте раздели проверку протокола, интеграции и качества ответа.
