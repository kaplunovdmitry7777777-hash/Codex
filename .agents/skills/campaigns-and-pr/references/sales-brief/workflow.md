Правила основного файла навыка имеют приоритет над примерами. Если пример предполагает конкретный путь, версию библиотеки или приложение, проверь доступный аналог.

Запустите анализ продаж и контент-брифинг. Соберите, что продалось (и что
нет), объясните почему, и выдайте готовый к использованию контент-план,
который действует по данным.

Разобрать аргументы:
- `--lookback` (по умолчанию: `30d`) — окно `30d`, `60d` или `90d`

## Шаг 1 — Разбивка продаж

Используя логику навыка `content-strategy` для анализа продаж:

1. Соберите поступления за период по банковской выписке / ЮKassa /
   эквайрингу, сгруппированные по товару/услуге/артикулу.
2. Соберите выручку по товарным категориям из выгрузки 1С (`1с_продажи.csv` /
   `продажи_по_дням.csv`).
3. Ранжируйте товары по: общей выручке, объёму в штуках и марже (если есть в
   выгрузке 1С).
4. Посчитайте долю каждого товара в общей выручке против аналогичного
   предыдущего периода.

Лидеры: товары, у которых выросла доля или которые удержались в топ-3.
Аутсайдеры: товары с падающим объёмом или долей выручки ниже 5%.

## Шаг 2 — Проверка на сезонность

1. Сравните текущий период с тем же периодом год назад (если есть история в
   1С).
2. Отметьте позиции с сезонным паттерном (например, всплеск в Q4, спад
   летом).
3. Отметьте новые товары, по которым истории недостаточно, чтобы определить
   сезонность.

## Шаг 3 — Анализ причин

Для каждого лидера и аутсайдера объясните вероятную причину:
- Изменение цены, акция, новый канал, сезонный спрос, ход конкурента
- Сверьтесь с активностью по кампаниям и сделкам в Битрикс24 (MCP) за период;
  если не подключён — с выгрузкой CRM из папки (`crm_клиенты.csv`)
- Отметьте, где атрибуция выведена по косвенным признакам, а где подтверждена

## Шаг 4 — 2-недельный контент-план

Подготовьте готовый к использованию контент-план:


## Если источник недоступен

Если недоступны и банковская выписка/ЮKassa/эквайринг, и выгрузка 1С —
остановитесь: анализ продаж требует хотя бы одного источника выручки. Если
подключён только один — работайте от него и отметьте, например, «Выгрузка 1С
не подключена — данные по выручке только из ЮKassa/эквайринга» (или
наоборот). Если Битрикс24 не подключён и нет CSV-выгрузки CRM — пропустите
сверку по кампаниям в «анализе причин» и отметьте это.

## Гейты одобрения

- **Никогда не публикуйте и не ставьте контент на автопубликацию.** Брифинг
  только для проверки владельцем.
- **Никогда не создавайте ассеты в Canva автоматически** — предложите
  сгенерировать их после того, как владелец одобрит брифинг. Учтите: доступ к
  Canva в РФ может быть ограничен — если сервис недоступен, предложите
  просто готовые тексты постов без визуала.

## Финальный шаг — очеловечить текст

Перед тем как показать владельцу контент-план, прогоните тексты угла подачи и
концепции постов через навык `humanizer-ru` (`skills/humanizer-ru/SKILL.md`):
убрать тире «—» и лишние двоеточия, канцелярит и штампы ИИ, выровнять ритм.
Названия товаров и цифры не менять.
