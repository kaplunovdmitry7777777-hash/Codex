# Выгрузка продаж (1С / ЮKassa / банковская выписка)

Для `content-strategy` источники данных — CSV-выгрузки из рабочей папки бизнеса, а не единый API вроде QuickBooks. Разные системы (1С, ЮKassa, интернет-банк) отдают разные форматы. Этот файл — памятка, как их читать надёжно.

## Текущее состояние

- Основной путь — CSV-файлы из рабочей папки бизнеса: `выписка_банка.csv`, `1с_продажи.csv` / `продажи_по_дням.csv`, `юkassa_платежи.csv` / `эквайринг.csv`, `crm_клиенты.csv`.
- Единой схемы колонок нет — разные версии 1С, разные банки и ЮKassa отдают разные названия полей.

## Что нужно учитывать при чтении

### 1. Разные кодировки и разделители

Выгрузки из 1С и старых банковских кабинетов нередко приходят в CP1251 с разделителем `;`, а не в привычном UTF-8 с запятой. Перед разбором:

1. Определите кодировку файла (сначала попробуйте UTF-8; при ошибках декодирования — CP1251).
2. Определите разделитель по первой строке (`,` или `;`).
3. Если формат даты нетиповой (`ДД.ММ.ГГГГ` вместо `ГГГГ-ММ-ДД`) — приведите к единому виду перед сравнением периодов.

### 2. Определение полей по смыслу, а не по названию колонки

Не требуйте точную схему. Ищите колонки по смыслу:

- **Дата** — колонка с датой операции/продажи.
- **Сумма/выручка** — колонка с суммой (может называться «сумма», «выручка», «итого», «amount»).
- **Товар/услуга** — наименование позиции (может называться «номенклатура», «товар», «услуга», «наименование»).
- **Количество** — если есть отдельная колонка штук/единиц.

### 3. Товарная категоризация в 1С

В 1С позиции продаж часто не имеют явной категории «товар/услуга» — только номенклатуру (SKU). Чтобы получить категории для контент-плана, сопоставляйте номенклатуру со справочником групп товаров, если он есть в выгрузке, либо группируйте по смыслу названия позиции.

### 4. Банковская выписка ≠ продажи по товарам

Банковская выписка показывает движение денег (поступления/списания), но обычно не показывает, какой товар или услугу купили. Используйте её для картины по кассе и общей выручке; для разбивки по товарам/услугам нужна выгрузка 1С или ЮKassa/эквайринга с детализацией по позициям.

## Что делать навыку, если данных не хватает

Если ни один файл не даёт нужной детализации (например, есть только банковская выписка без разбивки по товарам) — работайте с тем, что есть, и явно пометьте ограничение в плане: «Есть данные по общей выручке, но не по товарным категориям — рекомендации ниже общие, а не по конкретным позициям».

Никогда не додумывайте цифры, которых нет в выгрузке — при нехватке данных явно пишите «н/д» вместо оценки на глаз.
