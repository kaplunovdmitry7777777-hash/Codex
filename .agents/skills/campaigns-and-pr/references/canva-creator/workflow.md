# Подготовка материалов для Canva
Согласуй канал, аудиторию, формат, размеры и цель. Для серии составь календарь и таблицу вариантов с текстом, призывом к действию и визуальным брифом. Подготовь русские тексты и уточни, какие данные допустимо передавать в Canva.
При доступном приложении Canva прочитай схему поддерживаемых инструментов и выбери разрешённый шаблон. Если доступны поля автозаполнения, сначала проверь имена и типы полей, затем попробуй один вариант. Передавай только данные для выбранного шаблона. Проверь результаты, обрезку, шрифты, ссылки и соответствие формату. Представь ссылки, которые вернул коннектор. При отсутствии приложения выдай готовые тексты, размеры, макет и таблицу для ручной загрузки.
Для рассылки или соцсетей подготовь черновик и проверь дату, ссылки, аудиторию и соответствие бренд-гайду. Публикуй только в рамках явного поручения.
