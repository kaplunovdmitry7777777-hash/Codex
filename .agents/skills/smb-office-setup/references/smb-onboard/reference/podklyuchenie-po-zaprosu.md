# Подключение источников: база и коннекторы по запросу

Как ИИ помогает владельцу подключить данные. Главный принцип: **база — это
выгрузка CSV в папку. Её достаточно.** Живой коннектор предлагаешь только
когда владелец сам захотел живые данные, а не по умолчанию.

---

## База (по умолчанию) — файлы в папке

Ничего подключать не надо, VPN не нужен, работает всегда.

Скажи владельцу простыми словами:
- «Выгрузи из своего банка / 1С / ЮKassa / CRM файл (CSV или Excel) и
  положи в рабочую папку. Я сам разберусь с колонками, как бы они ни
  назывались.»
- Типовые файлы: `выписка_банка.csv`, `1с_продажи.csv`, `расходы.csv`,
  `счета_дебиторка.csv`, `crm_клиенты.csv`.
- «Раз в неделю обновил файл — 5 минут, и все сотрудники работают по
  свежим цифрам.»

Для большинства это финальная настройка. Не уговаривай идти дальше.

---

## Коннектор — только когда владелец сам попросит

Триггеры: «хочу подключить Битрикс24 вживую», «можно без ручной
выгрузки», «настрой живой коннектор», «подключи почту».

Правила разговора:
- Один коннектор за раз. Никогда не настраивай два параллельно.
- Простым языком. Говори, **что ты сможешь делать**, когда подключим («сам
  подтяну сделки по стадиям»), а не что такое сама платформа.
- **Кликает и авторизует всегда сам владелец.** Ты ведёшь по шагам, но не
  действуешь за него.
- Сразу назови честную оговорку про VPN (ниже). Не пробивается — спокойно
  возвращаемся к CSV, это не хуже.

### Битрикс24 (живой коннектор CRM) — пошагово

1. «Открой Битрикс24 → **Настройки → Для разработчиков → MCP-серверы** →
   включи доступ внешнему ИИ.»
2. «Скопируй адрес (endpoint), который портал выдал.»
3. «Рядом с плагином лежит файл `.mcp.json.example` — переименуй его в
   `.mcp.json`, вставь свой адрес вместо `https://ВАШ-ПОРТАЛ.bitrix24.ru/mcp/`,
   сохрани и перезапусти меня.»
4. Проверка вслух: «Скажи *кто мне должен* — если я подтянул сделки прямо
   из Битрикс24, коннектор живой.»
5. Закрывашка: «Готово. **Остальное подключается так же просто**: Gmail —
   тем же способом, а 1С / ЮKassa / банк вообще подключать не надо, просто
   кидаешь выгрузку в папку.»

### Gmail (почта) — тем же способом

Живой коннектор почты для писем должникам и договоров-вложений. Включается
в том же `.mcp.json` рядом с Битрикс24, авторизация по OAuth (Google-окно
входа открывает владелец). Яндекс/Mail.ru официального MCP не имеют —
оттуда пересылай нужное или выгружай файлом.

## Сервиса нет среди готовых коннекторов? (ЮKassa, банки, 1С, CRM, маркетплейсы)

Готовый MCP-коннектор к ассистент сегодня есть только у Битрикс24 и Gmail. У
остальных российских сервисов (ЮKassa, Сбер, Точка, Модульбанк, 1С, amoCRM,
МойСклад, Wildberries, Ozon…) готового нет — **но у всех есть открытый API.**
Значит, два пути:

1. **Сейчас, без кода — выгрузи файл (CSV/Excel) в папку.** Работает у всех,
   всегда, без VPN. Это база, её достаточно.
2. **Хочешь живые данные — под сервис пишется свой MCP-коннектор.** Ключ берётся
   в личном кабинете сервиса, сам коннектор собирается за вечер в ассистент Code.
   Готовые MCP под популярные РФ-сервисы выкладываются в Telegram-канале проекта
   «Иван — ИИ на практике» — бери оттуда готовый, если не хочешь собирать сам.

Что говорить владельцу: «Готового коннектора к этому сервису пока нет. Либо
выгружай файл (быстро и надёжно), либо ставь свой MCP — ссылку на готовый дам.
Файла достаточно; MCP — это про удобство и живые данные.»

⚠️ Не ставь случайные MCP с GitHub/npm для боевых данных без проверки: коннектор
к банку хранит ключи от счёта. Только то, чему доверяешь (свой или из канала проекта).

## Оговорка про VPN (называть честно, до настройки)

MCP-коннектор ходит на внешний сервис по сети. Из России он **не всегда
пробивается** — портал или Google-эндпоинт может быть недоступен без VPN.

Что говорить владельцу:
- «Если при подключении сервис не открывается — включи VPN и повтори шаг.»
- «Не хочешь возиться с VPN — просто выгрузи CSV в папку. Так надёжнее, и
  результат тот же, только данные не живые, а снимок на момент выгрузки.»

Вывод для владельца: коннектор — удобство, а не обязанность. База (CSV)
работает у всех и без VPN.

---

## Разница живой коннектор ↔ файл (одной фразой)

- **Коннектор:** данные живые, обновляются сами, но нужен доступ к сервису
  (возможно, VPN).
- **Файл:** снимок на момент выгрузки, обновляешь руками раз в неделю, зато
  работает всегда и без VPN.

Оба пути навыки читают одинаково хорошо. Выбор за владельцем.
