Правила основного файла навыка имеют приоритет над примерами. Если пример предполагает конкретный путь, версию библиотеки или приложение, проверь доступный аналог.

Запустите анализ цены. Заберите данные о себестоимости и выручке, постройте таблицу маржи и смоделируйте три ценовых сценария — чтобы владелец увидел цифры ясно, прежде чем решать, сколько брать за товар или услугу.

Разобрать аргументы:
- `PRODUCT_NAME` (необязательно) — конкретный товар или услуга для анализа; если не указан — разобрать все активные позиции

## Шаг 1 — Текущая база по марже

Используя workflow навыка `margin-analyzer`:

1. Забрать выручку по товару/услуге за последние 90 дней — из выгрузки продаж 1С / ЮKassa / эквайринга (CSV из рабочей папки бизнеса).
2. Забрать себестоимость или прямые расходы по каждой позиции — из выгрузки 1С или файла расходов (если расходы разнесены по позициям).
3. Сверить с данными ЮKassa/эквайринга за тот же период для перекрёстной проверки.
4. Посчитать текущую валовую маржу по каждой позиции: (выручка − себестоимость) ÷ выручка.

Построить таблицу маржи:

```
Товар/услуга     | Выручка   | Себестоимость | Валовая прибыль | Маржа %
{товар}          | {сумма} ₽ | {сумма} ₽      | {сумма} ₽        | {X}%
```

Отметить как риск любую позицию с маржой ниже 20%.

## Шаг 2 — Три ценовых сценария

По каждому товару (или указанному товару) смоделировать три сценария. НЕ рекомендовать цену — только показать данные.

**Сценарий A — Оставить текущую цену**
- Прогноз выручки при текущей цене × текущем объёме
- Прогноз маржи при текущей себестоимости

**Сценарий B — Повышение цены (+10% до +20%, владелец уточняет диапазон)**
- Прогноз выручки при потере объёма 0%, 5% и 10% при новой цене
- Показать точку безубыточности по объёму, чтобы сохранить текущую прибыль

**Сценарий C — Снижение цены (−10%, чтобы нарастить объём)**
- Прогноз выручки при росте объёма на 10%, 20% и 30%
- Показать объём, нужный для сохранения текущей прибыли

Показать каждый сценарий таблицей данных, а не рекомендацией.

## Шаг 3 — Бриф для сообщения клиентам

Подготовить бриф простым языком (для сценариев с повышением цены), который владелец сможет использовать, чтобы сообщить об изменении клиентам:
- Один абзац с объяснением изменения
- Три варианта ключевого сообщения (прямой, на ценности, эмпатичный)
- Рекомендуемое время и канал (письмо, пометка в счёте, разговор лично)

## Отказ источников

Если недоступна выгрузка 1С/банковская выписка — остановиться: анализ маржи требует данных и о выручке, и о себестоимости. Если недоступна ЮKassa/эквайринг — работать только на данных 1С/выписки и отметить: «ЮKassa/эквайринг не подключены — перекрёстная проверка по продажам через них пропущена».

## Гейты одобрения

- **Никогда не рекомендовать конкретную цену.** Только данные — решение о цене остаётся за владельцем.
- **Отметить, если данные по себестоимости неполные** (во многих учётных системах себестоимость не разнесена по позициям), и указать этот пробел.
- **Никогда не менять цены** ни в 1С, ни в ЮKassa, ни в любой другой подключённой системе.

## Вывод

Показать таблицу маржи, затем три таблицы сценариев рядом. Если рассматривается сценарий повышения цены — добавить бриф для сообщения клиентам. Завершить вопросом: «Какой сценарий разобрать подробнее?»
