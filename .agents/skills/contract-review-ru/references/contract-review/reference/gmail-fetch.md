# Gmail: поиск вложений с договором

Используйте коннектор Gmail MCP, чтобы найти вложения с договором в недавней почте.

## Поиск писем с договором

Используйте `search_threads` с запросом, нацеленным на недавние письма с вложениями:

```
Query: "has:attachment (договор OR соглашение OR contract OR agreement OR NDA) newer_than:14d"
```

## Что делать с результатами

1. Если подходит несколько писем — показать короткий список (тема, отправитель, дата).
2. Спросить у владельца, какое из них скачивать, прежде чем открывать вложение.
3. Использовать `get_thread`, чтобы получить всю переписку целиком, затем найти и прочитать вложение.

## Запасной вариант

Если Gmail не подключён или подходящее вложение не найдено:

```
"Не нашёл подходящего вложения с договором в Gmail — пришлите его файлом или вставьте текст напрямую."
```

## Чего не делать

- Не читать письма, не относящиеся к договору (никакого просмотра всей почты подряд).
- Не отправлять никакие ответы и не создавать черновики писем в процессе разбора договора.


Для краткого разбора выдай резюме, красные флаги и черновики формулировок с привязкой к пунктам. Укажи вопросы юристу.
