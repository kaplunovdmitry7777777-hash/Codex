# Оценка поставщиков: рейтинг, претензии, риски

Действовать как руководитель службы МТО и одновременно аудитор качества поставок. Задача: регулярная (ежеквартальная) **оценка уже работающих поставщиков**, чтобы решение о продлении договора было подготовлено заранее. Выбор категорий и консолидация относятся к навыку `zakupki-optimizaciya`.

Оценка поставщиков — требование ГОСТ Р ИСО 9001-2015 п. 8.4.1: критерии оценки, выбора, мониторинга и повторной оценки должны быть установлены, результаты зарегистрированы.

## Когда применять

- Ежеквартальный рейтинг поставщиков для совещания у ГД или для анализа СМК руководством.
- Поставщик регулярно срывает сроки или поставляет несоответствующую продукцию (засор лома, огнеупоры с низкой стойкостью, валки с дефектами).
- За 60–90 дней до окончания договора нужно обоснованное решение: продлить, продлить с условиями, искать замену.
- СБ дала заключение о повышенном риске по действующему контрагенту.

## Исходные данные

Одна строка на поставщика за период: Поставщик; Категория; Критичность (1/2/3); Сумма; Поставок всего; Поставок в срок; Партий с несоответствием; Претензий; Отклонение цены, %; Отсрочка, дн; Риск контрагента (низкий/средний/высокий); Договор до.

Источники: 1С (поступления, даты по договору и факту), журнал входного контроля / акты о браке (ОТК, ЦЗЛ), реестр претензий, заключения СБ, мониторинг рыночных цен (биржевые котировки лома, прайсы конкурентов).

Не заполнять пропуски выдуманными цифрами. Если критерия нет, скрипт пересчитывает итог по оставшимся весам; указать это в отчёте.

## Порядок работы

1. Собрать таблицу и согласовать с пользователем веса. По умолчанию: своевременность 30, качество 30, цена 20, условия оплаты 10, надёжность 10. Для сырья и энергоресурсов можно поднять вес цены, для запчастей импортного оборудования — вес надёжности.
2. Запустить `python3 scripts/reiting_postavschikov.py --input <файл> --out reiting.md [--vesa 30,30,20,10,10]` (путь относительно папки навыка).
3. Для каждого вердикта ЗАМЕНИТЬ и РАЗОБРАТЬ указать конкретную причину: какой критерий провален и на каких фактах (номера актов, партии, даты).
4. **Претензии и штрафы.** По поставщикам с несоответствиями проверить, выставлены ли претензии по договору (неустойка за просрочку, возмещение за брак, засор). Если несоответствия есть, а претензий нет, выделить это отдельно: завод теряет деньги.
5. **План на случай срыва.** Для каждого поставщика критичности 1 спросить: что будет, если поставки прекратятся завтра? Сколько суток работы агрегата обеспечивает склад, есть ли допущенный аналог и резервный поставщик?
6. Свести итог (см. «Формат вывода»).

## Формат вывода

- Вывод в 3–5 строк: кого заменить, с кем говорить, где завод недополучает по претензиям.
- Таблица рейтинга (скрипт).
- ТОП-3 ОСТАВИТЬ (можно расширять сотрудничество), ТОП-3 РАЗОБРАТЬ (повестка встречи), все ЗАМЕНИТЬ (кто ищет альтернативу и в какой срок).
- Невыставленные претензии с оценкой суммы.
- Критичные поставщики без плана на случай срыва поставки.

## Контрольные вопросы

1. Критичность определена по влиянию на производство или по сумме закупки? Правильно — по влиянию: дешёвый поставщик уплотнений для гидросистемы стана может быть критичнее крупного поставщика СИЗ.
2. Своевременность считается по дате в договоре или по дате, перенесённой допсоглашением?
3. Данные о несоответствиях берутся из журнала входного контроля или со слов цеха?
4. Когда последний раз по договору выставлялась неустойка?
5. Есть ли по критичным поставщикам свежее (не старше 12 месяцев) заключение СБ?
6. Что будет в первые 72 часа, если поставщик исчезнет?

## Ошибки, которых избегать

- Оценивать всех поставщиков одинаково, без учёта критичности.
- Пересматривать поставщика только при продлении договора: для критичности 1 оценка нужна ежеквартально, для 2 раз в полгода, для 3 при продлении.
- Ставить оценку «по ощущениям». Смысл навыка в том, чтобы два разных специалиста получили одинаковый результат на одних данных.
- Ограничиваться анкетой поставщика без проверки фактов (выписка ЕГРЮЛ, арбитражные дела, сертификаты, аудит производства поставщика).
