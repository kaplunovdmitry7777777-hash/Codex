# Оптимизация закупок: категории, концентрация, цикл

Действовать как директор по закупкам / экономист по МТО металлургического завода. Задача навыка: **что покупать, у кого и как быстро**. Оценка работы уже выбранного поставщика (сроки, качество, претензии) относится к навыку `ocenka-postavschikov`.

## Когда применять

- Годовой или квартальный анализ затрат на МТР и услуги.
- Нужно понять, какие 3–5 категорий дали основной рост затрат.
- Подозрение на дробление закупок: много поставщиков одной номенклатуры (подшипники, СИЗ, РТИ, метизы).
- Заявки на запчасти/валки/импортные позиции идут месяцами, нужно найти этап, где они стоят.
- Подготовка решения о консолидации поставщиков или о резервировании единственного источника.

## Исходные данные

Запросить у пользователя (или найти в подключённой папке) выгрузки 1С:

1. **Затраты за период** (оборотка по 60/76 сч. или «Анализ закупок»): Поставщик; Категория; Номенклатура; Сумма (без НДС); Сумма пред. период; Единственный источник (да/нет); Критичность (1/2/3).
2. **Реестр заявок** (для цикла): № заявки; Категория; Дата заявки; Дата согласования; Дата заказа; Дата поставки; Дата оплаты; Согласующих.

Критичность задаёт пользователь, не выводить её из сумм:
- **1** — срыв поставки останавливает агрегат/цех (лом, электроэнергия, электроды, огнеупоры, валки, газы);
- **2** — есть обходной вариант (склад, аналог, ремонт);
- **3** — некритично.

Если колонки называются иначе, переименовать или сопоставить. Если категорий нет, сначала сгруппировать номенклатуру по категориям и показать пользователю на согласование.

## Порядок работы

1. **ABC-анализ.** Запустить `python3 scripts/abc_zakupok.py --input <файл> --out abc.md` (путь относительно папки навыка). Результат: классы A/B/C по категориям, топ-5 драйверов роста, монозависимость в критичных категориях, «хвост» поставщиков группы C.
2. **Цикл закупки.** Запустить `python3 scripts/cikl_zakupok.py --input <заявки> --out cikl.md`. Категория с медианой цикла больше 2× общей отмечается как **узкое место**, указывается этап задержки (согласование / размещение заказа / поставка).
3. **Консолидация.** По категориям-кандидатам (≥ 3 поставщиков, критичность 2–3) рассчитать вручную:
   - экономию = текущие затраты кластера − затраты у победителя − затраты на переход (переаттестация, испытания, изменение ТУ/спецификаций, запас на переходный период);
   - **не рекомендовать** сведение к единственному поставщику в категории критичности 1 без документированного плана на случай срыва поставки (резервный поставщик, страховой запас в сутках работы агрегата, допуск аналога).
4. **Календарь договоров.** Если есть сроки договоров, отметить месяцы, где истекают ≥ 3 договора одной категории: в такой месяц у завода нет переговорной позиции, сроки нужно разнести.
5. **Сводка для ГД.** Свести в одну страницу (см. «Формат вывода»).

## Формат вывода

Начать с вывода в 3–5 строк, затем таблицы:

- топ-5 категорий по приросту затрат (млн руб., %);
- узкие места цикла закупки (категория, медиана/P90, этап задержки);
- топ-5 возможностей консолидации с оценкой экономии и рисков;
- критичные категории с монозависимостью и отсутствием плана на случай срыва;
- рекомендации с ответственным и сроком.

Суммы в млн руб. без НДС, разделитель тысяч пробел, десятичная запятая. Для Excel-отчёта использовать навык xlsx, для служебной записки — docx.

## Контрольные вопросы (задавать по одному)

1. Категории сформированы по тому, *что* покупается, или по поставщикам? Один поставщик может закрывать несколько категорий.
2. Какие 3 категории выросли сильнее всего и почему: цена, объём, курс, новая номенклатура?
3. Для каждой консолидации: какова стоимость перехода и не превышает ли она экономию?
4. По категориям критичности 1 с единственным источником: какой план на 72 часа, если поставка сорвётся?
5. Какая доля закупок идёт без конкурентной процедуры (срочные, «у единственного», через подотчёт)?
6. Сколько договоров в топ-20 истекают в одном месяце?
7. Есть ли порог, ниже которого закупка согласуется упрощённо, и кто владелец этой «мелочи»?

## Ошибки, которых избегать

- Сводить критичную категорию к одному поставщику ради скидки без плана резервирования.
- Считать экономию без затрат на переход и испытания нового материала (огнеупоры, электроды, валки).
- Сравнивать цены без учёта базиса поставки, отсрочки платежа и качества (засор лома, стойкость футеровки).
- Оценивать цикл закупки по среднему: среднее скрывает отдельные заявки, которые стоят месяцами. Смотреть медиану и P90.
- Предлагать решение вместо пользователя: результат навыка служит основой для решения, само решение принимает ГД.

## Правовой контур

Если предприятие подпадает под 223-ФЗ, рекомендации по консолидации и выбору способа закупки сверять с Положением о закупке. Проверку благонадёжности контрагентов выполнять отдельно (СБ, навык анализа контрагентов).
