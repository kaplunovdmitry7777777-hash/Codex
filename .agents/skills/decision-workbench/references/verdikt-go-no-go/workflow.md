# Вердикт GO / NO-GO

Цель: вместо рассуждений дать руководителю решение по шкале, с критериями, доказательствами и условиями. Подходит для любого направления: выбор поставщика или подрядчика, инвестпроект, договор, готовность агрегата к пуску, готовность к аудиту, внедрение ИТ-системы.

## Два режима

| Режим | Когда | Шкала |
|---|---|---|
| **Выбор** | Сравнить варианты или решить «делать / не делать» | GO / CONDITIONAL GO / NO-GO |
| **Диагностика** | Проверить состояние объекта, процесса, документа | GREEN / YELLOW / RED |

Если режим неясен из запроса — выбери по смыслу и назови его в первой строке ответа.

## Шаги

1. **Предмет и решение.** Одной фразой: что оцениваем и какое решение примет руководитель по итогам.
2. **Критерии.** 5–8 критериев. Для каждого:
   - вес (сумма 100 %) или пометка **«стоп-критерий»** (провал = NO-GO / RED независимо от остального);
   - порог прохождения в измеримом виде (цифра, наличие документа, срок).
   Типовые стоп-критерии: промышленная и пожарная безопасность, законность, санкционные и СБ-риски контрагента, отсутствие обязательных разрешений.
   Если пользователь не дал критерии — предложи свои и сразу продолжай, пометив их «предложены».
3. **Сбор фактов.** Только из предоставленных файлов, подключённых источников или открытых страниц. У каждого факта — источник. Чего нет — пометка «нет данных», не догадка.
4. **Оценка по критериям.** Таблица: критерий · вес · порог · факт · источник · оценка (✓ / ≈ / ✗ или 0–10).
5. **Вердикт.**
   - GO / GREEN — все стоп-критерии пройдены, взвешенный итог ≥ 75 %.
   - CONDITIONAL GO / YELLOW — стоп-критерии пройдены, итог 50–75 % или есть устранимые пробелы. Обязательно перечислить условия: что сделать, кто, к какому сроку.
   - NO-GO / RED — провален стоп-критерий или итог < 50 %.
   Пороги можно менять по просьбе пользователя.
6. **Чувствительность.** Одна строка: какой один факт, если окажется другим, меняет вердикт.

## Формат ответа

```
ВЕРДИКТ: CONDITIONAL GO (68 %)
Одна фраза — почему.

| Критерий | Вес | Порог | Факт | Источник | Оценка |

Условия (для CONDITIONAL / YELLOW):
1. … — ответственный — срок

Риски: 2–4 пункта.
Что меняет вердикт: …
Нет данных: … (что запросить и у кого)
```

Несколько вариантов — общая таблица «вариант × критерий» и вердикт по каждому; лучший вариант первым.

## Правила

- **Только чтение.** Навык оценивает, ничего не меняет, не отправляет, не согласует.
- **Сначала план, потом изменения.** Если по итогам нужны действия, оформи их планом и жди подтверждения.
- Не завышать: при нехватке данных по стоп-критерию вердикт не выше CONDITIONAL GO / YELLOW.
- Цифры проверять вычислением (взвешенный итог считать, а не прикидывать).
- Финансовые и юридические выводы — с пометкой, что это аналитика, а не заключение юриста или финансового консультанта.
- Коротко: вердикт первой строкой, вся оценка — на один экран, где возможно.
