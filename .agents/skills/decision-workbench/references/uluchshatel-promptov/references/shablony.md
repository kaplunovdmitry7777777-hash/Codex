# Шаблоны промптов по типам задач

Шаблоны — каркас, а не форма для заполнения. Бери нужные блоки, выбрасывай лишние.

## Содержание
1. Анализ данных / таблиц
2. Анализ корпуса документов
3. Отчёт, дашборд, презентация для руководства
4. Письмо, приказ, служебная записка
5. Исследование и сравнение вариантов
6. Проверка, расследование, аудит
7. Код, автоматизация, бот
8. Инструкция для Проекта / системный промпт

---

## 1. Анализ данных / таблиц

```
Контекст: [предприятие, подразделение], [период]. Данные — выгрузка из [1С / MES / Excel], файл [имя], лист [имя].
Колонки: [A — дата, B — цех, C — сумма, руб. без НДС …]. Единицы: [т, руб., шт.].

Задача: [что посчитать / найти]. Результат нужен для [решения: например, сокращение затрат на ремонт стана 900].

Требования к точности:
- Все цифры — только из файла; для ключевых выводов укажи лист и строки.
- Перед выводами проверь данные: дубли, пустые значения, выбросы, несоответствие единиц. Опиши найденное.
- Допущения и оценки помечай словом «допущение».
- Если данных не хватает для вывода — скажи, каких именно.

Формат: [таблица топ-N по …; диаграмма …; вывод в 3–5 пунктах в начале].
```

## 2. Анализ корпуса документов

```
В папке [путь] — [N] документов: [договоры поставки / приказы / акты]. Формат: [PDF-сканы / docx].

Задача: [извлечь …, сверить …, найти …].

Порядок: сначала составь перечень документов (имя файла, тип, дата, стороны), затем [основная задача].
Для каждого вывода — ссылка: файл, страница/пункт.
Если документ не читается или неполный — отметь в отдельном списке, не пропускай молча.

Результат: [Excel-реестр с колонками … / сводка с таблицей рисков].
```

## 3. Отчёт, дашборд, презентация для руководства

```
Аудитория: [генеральный директор / совет директоров / собственник]. Читают [5 минут / на совещании].
Тема: [например, состояние оборудования стана 900/680 за Q3].
Исходные данные: [файлы].

Структура:
1. Главный вывод — 1–2 предложения.
2. Ключевые показатели: [план/факт, отклонение, динамика к прошлому периоду].
3. Проблемы и причины — с цифрами.
4. Решения: что, кто, срок, эффект в руб./т/ч.

Формат: [HTML-дашборд / презентация на N слайдов / Excel с цветовой индикацией].
Цвета: красный — критично, жёлтый — внимание, зелёный — норма. Пороги: [указать].
Цифры — только из данных, источник под каждым графиком.
```

## 4. Письмо, приказ, служебная записка

```
Тип документа: [письмо контрагенту / приказ / служебная записка / ответ на претензию].
От кого — кому: [должность → должность / организация].
Повод: [факты: даты, номера договоров, суммы].
Цель: [чего добиться: оплата до …, отказ, согласование].
Тон: [официально-нейтральный / жёсткий, но корректный].
Ограничения: [ссылки на п. … договора, ТК РФ ст. …; не признавать …].
Объём: [до 1 страницы].
```

## 5. Исследование и сравнение вариантов

```
Вопрос: [что выбрать / как устроен рынок …].
Варианты: [перечислить или «найди 3–5 основных»].
Критерии сравнения: [цена, сроки, надёжность, совместимость с …, требования 223-ФЗ].
Источники: официальные сайты производителей, отраслевые издания, данные ФНС/ЕГРЮЛ; для каждого факта — ссылка.
Актуальность: данные не старше [года].
Результат: сравнительная таблица + рекомендация с обоснованием и рисками.
```

## 6. Проверка, расследование, аудит

```
Предмет проверки: [например, приёмка металлолома в цехе № … за период …].
Гипотезы: [что подозреваем].
Данные: [журналы КПП, 1С, акты, табели — файлы].
Методика: сопоставить [A] с [B] по [ключ: дата, смена, номер ТС]; выявить расхождения > [порог].
Требования: каждое расхождение — с ссылкой на строки обоих источников; разделять «факт» и «предположение»; не делать выводов о виновности конкретных лиц — только о расхождениях.
Результат: реестр расхождений (Excel) + сводка для СБ.
```

## 7. Код, автоматизация, бот

```
Что автоматизируем: [процесс, сейчас делается вручную так: …].
Вход: [файлы/API, пример входа]. Выход: [пример результата].
Среда: [Python 3.x, Windows, без доступа в интернет / 1С …].
Требования: [обработка ошибок, лог, повторный запуск без дублей].
Сначала предложи архитектуру и задай вопросы; код — после согласования.
```

## 8. Инструкция для Проекта / системный промпт

```
Ты — [роль: аналитик по закупкам металлургического предприятия].
Пользователь — [кто, что ему важно].
Твои задачи в этом Проекте: [перечень типовых запросов].
Источники: файлы Проекта [перечень]; при противоречии приоритет у [документа].
Правила точности: [только из данных, ссылки, пометка допущений].
Формат ответов по умолчанию: [лаконично, вывод первым, таблицы для сравнений, русский язык].
Чего не делать: [не давать юридических заключений без оговорки …].
```
