# Корректирующие действия (КД) и анализ причин

Действовать как уполномоченный по качеству / руководитель ОТК и ЦЗЛ. Задача: довести каждое значимое несоответствие до устранения **причины**, а не симптома, и доказать результативность фактами.

Нормативная база: ГОСТ Р ИСО 9001-2015 — п. 8.7 (управление несоответствующими выходами), п. 10.2 (несоответствия и корректирующие действия), п. 9.3 (входы анализа руководством). При работе с автомобильной продукцией дополнительно IATF 16949 (обязательный 8D).

Термины: **коррекция** — устранение конкретного несоответствия (переаттестация, перевод в другую марку, доработка, изоляция партии); **корректирующее действие** — устранение причины, чтобы не повторилось; **предупреждающее** — распространение мер на аналогичные агрегаты и процессы.

## Когда открывать КД

| Источник | КД обязательно | Критерий |
|---|---|---|
| Рекламация покупателя | Да | Любая обоснованная рекламация |
| Внешний аудит (сертификационный, покупателя) | Да | Все несоответствия |
| Внутренний аудит: значительное несоответствие | Да | Системный сбой или отсутствие элемента СМК |
| Внутренний аудит: незначительное | Рекомендуется | Единичный сбой |
| НП (несоответствующая продукция) повторяющаяся | Да | Один вид дефекта ≥ 3 раз за период или рост доли брака |
| НП единичная | Оценить | По тоннажу, стоимости, риску для покупателя |
| Анализ данных (тренды брака, расходных коэффициентов) | Оценить | Устойчивый негативный тренд |
| Нарушения ОТ и ПБ | Да | Через процедуры ОТ, с увязкой с КД СМК |

## Порядок разбора (8D)

| Шаг | Содержание | Срок-ориентир |
|---|---|---|
| D1 | Команда: владелец процесса, технолог, ОТК/ЦЗЛ, механик/энергетик при необходимости | 1 сутки |
| D2 | Описание проблемы: что, где, когда, сколько (т, плавки, партии, покупатели), как обнаружено. Формат «есть/нет» | 1–2 суток |
| D3 | Сдерживающие меры: изоляция партий в изоляторе брака, 100 % контроль, уведомление покупателя | 24–72 часа |
| D4 | Корневая причина и причина невыявления (почему не поймал контроль) | до 2 недель |
| D5 | Выбор КД и доказательство, что они устраняют причину | |
| D6 | Внедрение КД, снятие сдерживающих мер | 30–90 дней |
| D7 | Предупреждающие меры: другие агрегаты, марки, процессы; изменение ТИ, СТП, FMEA | 60–120 дней |
| D8 | Закрытие, признание работы команды | |

### Выбор метода анализа причин

```
Несчастный случай, авария, отказ с тяжёлыми последствиями? → дерево отказов (FTA)
Подозревается ошибка персонала? → анализ человеческого фактора (почему ошибка стала возможной)
Причин 1–2, цепочка линейная? → «5 почему»
Причин 3–6, системная проблема? → диаграмма Исикавы (6М) + проверка гипотез данными
Причина неизвестна, нужно предупредить? → FMEA (навык analiz-riskov-fmea)
```

### Исикава (6М) для металлургии

| Категория | Что проверять |
|---|---|
| Человек | Квалификация, допуск, смена/бригада, сверхурочные, соблюдение ТИ |
| Машина (оборудование) | Износ (гильзы кристаллизатора, валки, проводки), настройка, ППР, отказы |
| Метод (технология) | ТИ, режимы (температура разливки, скорость, обжатия, нагрев), изменения |
| Материал | Лом (засор, химсостав), ферросплавы, огнеупоры, заготовка от смежного цеха |
| Измерение | Поверка СИ, методика контроля, точность, человеческая оценка дефекта |
| Среда | Температура, влажность, сезонность (зимний лом), вода, энергоснабжение |

Шаблоны «5 почему», 8D и пример по трещинам на заготовке — в `references/8d-i-5-pochemu.md`.

### Проверка корневой причины (до планирования КД)

- [ ] Причина подтверждена фактами (данные, эксперимент, металлография), а не мнением.
- [ ] Если причину устранить, проблема не повторится.
- [ ] Причина в зоне управления предприятия.
- [ ] Причина объясняет все признаки (время, агрегат, марку, бригаду).
- [ ] Других значимых причин не осталось.

«Человеческий фактор» и «нарушение ТИ» не являются корневой причиной: нужно выяснить, почему нарушение стало возможным и не было обнаружено.

## План КД

Для каждого действия: тип (коррекция / КД / предупреждающее), ответственный, срок, ресурсы, измеримый критерий успеха, способ проверки. Плохие формулировки: «усилить контроль», «провести беседу», «обратить внимание». Хорошие: «внести в ТИ ограничение скорости разливки 2,8 м/мин для сечения 150 при перегреве > 35 °C; контроль по АСУ ТП».

## Проверка результативности

| Значимость | Выждать после внедрения | Окно проверки |
|---|---|---|
| Критическое | 30 дней | 30–90 дней |
| Значительное | 60 дней | 60–180 дней |
| Незначительное | 90 дней | 90–365 дней |

```
Повторилось за период проверки? → да → НЕРЕЗУЛЬТАТИВНО, повторный анализ причин
                                → нет → критерии успеха достигнуты? → да → закрыть
                                                                    → нет → продлить проверку или пересмотреть КД
```

Методы: сравнение доли брака до/после, аудит процесса, выборка записей, контроль продукции.

## Реестр и показатели

Запустить `python3 scripts/reestr_kd.py --input КД.csv [--na-datu ДД.ММ.ГГГГ] --out kd.md` (путь относительно папки навыка). Колонки описаны в начале скрипта.

| Показатель | Ориентир |
|---|---|
| Средний цикл закрытия | < 60 дней |
| Доля просроченных | < 10 % |
| Результативность с первого раза | > 90 % |
| Повтор после закрытия | < 5 % |
| Корневая причина установлена в течение 30 дней | 100 % |

Возраст открытых КД: 0–30 дней в работе; 31–60 контроль; 61–90 эскалация руководству; > 90 вмешательство ГД/представителя руководства по качеству.

## Формат вывода

Для разбора: 8D-отчёт (D1–D8) в docx или документ. Для реестра: вывод в 3–5 строк, таблица показателей, просроченные, нерезультативные и повторившиеся КД, предложения для анализа СМК руководством.
