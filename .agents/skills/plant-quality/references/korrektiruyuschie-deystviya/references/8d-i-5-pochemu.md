# Шаблоны: 8D-отчёт, «5 почему», пример разбора

## Шаблон 8D-отчёта

```
8D-ОТЧЁТ № ____            Дата открытия: __.__.____
Продукция / марка / профиль: ____________   Покупатель (если рекламация): ____________

D1. Команда
    Руководитель: ________ (должность)   Участники: ________

D2. Описание проблемы
    Что: ________  Где (агрегат, участок): ________  Когда обнаружено: ________
    Сколько: ___ т / ___ плавок / ___ партий       Как обнаружено: ________
    ЕСТЬ / НЕТ: на каком агрегате есть — на каком нет; в какие смены есть — нет; какие марки есть — нет

D3. Сдерживающие меры (24–72 ч)
    - Изолировано: ___ т (номера плавок/партий), место: изолятор брака
    - Усиленный контроль: ________  до: __.__.____
    - Уведомление покупателя: да/нет, дата

D4. Корневая причина
    Причина возникновения: ________  Подтверждение (данные, эксперимент): ________
    Причина невыявления (почему не обнаружил контроль): ________

D5. Выбранные КД и доказательство их действенности
D6. Внедрение: действие — ответственный — срок — отметка о выполнении
D7. Предупреждающие меры: аналогичные агрегаты/марки; изменённые ТИ, СТП, FMEA, план контроля
D8. Закрытие: результативность подтверждена (данные до/после), дата, подпись руководителя
```

## Шаблон «5 почему»

```
ПРОБЛЕМА: [конкретно: что, где, сколько]

ПОЧЕМУ 1: Почему [проблема]?        ПОТОМУ ЧТО: ____   ФАКТ: ____
ПОЧЕМУ 2: Почему [причина 1]?       ПОТОМУ ЧТО: ____   ФАКТ: ____
ПОЧЕМУ 3: …
ПОЧЕМУ 4: …
ПОЧЕМУ 5: …                         КОРНЕВАЯ ПРИЧИНА: ____
```

Каждый ответ подтверждать фактом (запись, данные АСУ ТП, протокол ЦЗЛ). Останавливаться, когда дошли до причины в системе управления (процедура, стандарт, ресурс), которую можно изменить. Пять — ориентир, не норма.

## Пример: продольные трещины на заготовке 150×150

```
ПРОБЛЕМА: за июль на МНЛЗ-1 забраковано 520 т заготовки 150×150 по продольным трещинам (ручей 2 и 3).

ПОЧЕМУ 1: Почему трещины?
  ПОТОМУ ЧТО: неравномерное формирование корочки в кристаллизаторе.
  ФАКТ: металлография — трещины от поверхности, глубина до 3 мм; распределение по ручьям.
ПОЧЕМУ 2: Почему неравномерная корочка на ручьях 2 и 3?
  ПОТОМУ ЧТО: износ гильз кристаллизатора выше допустимого (конусность ниже нормы).
  ФАКТ: замеры гильз — ручьи 2 и 3 отработали 1 150 и 1 210 плавок при норме 900.
ПОЧЕМУ 3: Почему гильзы работали сверх нормы?
  ПОТОМУ ЧТО: не было запасных гильз на складе.
  ФАКТ: складская карточка — остаток 0 с 12.06.
ПОЧЕМУ 4: Почему не было запаса?
  ПОТОМУ ЧТО: заявка подана при нулевом остатке, срок поставки 8 недель.
  ФАКТ: дата заявки 14.06, договор 29.07.
ПОЧЕМУ 5: Почему заявка подана так поздно?
  ПОТОМУ ЧТО: для гильз не установлен минимальный складской запас с учётом срока поставки.
  ФАКТ: позиция отсутствует в перечне критичных запчастей.

КОРНЕВАЯ ПРИЧИНА: нет нормы неснижаемого запаса гильз кристаллизатора с учётом срока поставки.
ПРИЧИНА НЕВЫЯВЛЕНИЯ: работа сверх нормы стойкости не блокируется — допускается решением мастера.

КД: 1) включить гильзы в перечень критичных запчастей, минимум = расход за 10 недель; 2) запрет работы сверх
нормы стойкости без решения главного механика и технолога; 3) учёт стойкости в АСУ с предупреждением на 90 %.
Предупреждающие: проверить по тому же принципу проводки и валки станов.
Проверка результативности: брак по продольным трещинам ≤ 0,2 % в течение 3 месяцев.
```
