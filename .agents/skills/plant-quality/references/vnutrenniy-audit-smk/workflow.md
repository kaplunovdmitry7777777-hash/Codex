# Внутренний аудит СМК (ГОСТ Р ИСО 9001-2015)

Действовать как ведущий внутренний аудитор СМК металлургического предприятия. Задача: проверять, что процессы работают так, как описано, и дают результат, а не искать виноватых.

Нормативная база: ГОСТ Р ИСО 9001-2015 (п. 9.2 — внутренний аудит), ГОСТ Р ИСО 19011-2021 (руководящие указания по аудиту). При поставках по требованиям отраслевых стандартов (IATF 16949, требования атомной отрасли, РМРС, сертификация арматуры) добавлять их требования к критериям аудита.

## 1. Программа аудитов

1. Составить перечень процессов СМК с пунктами ISO 9001, владельцами и уровнем риска.
2. Риск процесса оценивать по влиянию на продукцию и покупателя, истории несоответствий и рекламаций, изменениям.
3. Периодичность: высокий риск — раз в 6 месяцев, средний — раз в 12, низкий — раз в 24. Открытые несоответствия или существенные изменения (новое оборудование, оргструктура, ТИ) повышают уровень на ступень.
4. Запустить `python3 scripts/programma_auditov.py --input процессы.csv --god <год> --out programma.md` (путь относительно папки навыка). Скрипт выдаёт сроки следующих аудитов, просроченные аудиты, помесячный график и непокрытые пункты стандарта.
5. Проверить, что за цикл сертификации (3 года) охвачены все пункты 4–10 и все площадки/цеха.
6. Назначить аудиторов с проверкой независимости.

### Независимость аудитора

- [ ] Не отвечает за проверяемую деятельность.
- [ ] Не подчиняется напрямую руководителю проверяемого подразделения.
- [ ] Не участвовал в проверяемой работе в последние 12 месяцев.
- [ ] Обучен и имеет квалификацию для этой области.

## 2. Проведение аудита

1. План аудита: цели, область, критерии (пункты стандарта, СТП, ТИ, договорные требования), график, аудиторы.
2. Изучить документы до аудита: СТП процесса, ТИ, показатели, предыдущие несоответствия и КД.
3. Вступительное совещание с владельцем процесса.
4. Сбор свидетельств: документы, записи, интервью, наблюдение на рабочем месте, прослеживание (от заказа до отгрузки, от плавки до сертификата качества).
5. Классификация находок (раздел 3).
6. Заключительное совещание: предварительные выводы.
7. Отчёт в течение 5 рабочих дней.

Чек-листы по процессам металлургического завода — в `references/chek-listy-iso9001.md`.

### Запись находки

```
Требование: [пункт ГОСТ Р ИСО 9001 / СТП / ТИ — дословно или близко к тексту]
Свидетельство: [что увидено/прочитано/услышано: документ, номер, дата, место, лицо]
Несоответствие: [в чём расхождение]
```

Пример:
```
Требование: ГОСТ Р ИСО 9001-2015 п. 7.1.5.2 — средства измерений поверяются/калибруются через установленные интервалы.
Свидетельство: весы автомобильные № 3 на складе лома, свидетельство о поверке до 15.08.2026; на 06.10.2026 используются
               при приёмке лома (журнал взвешиваний за 01–05.10.2026, 47 записей).
Несоответствие: СИ с истёкшим сроком поверки используется для учёта сырья.
```

## 3. Классификация

| Категория | Определение | Примеры |
|---|---|---|
| Значительное несоответствие | Отсутствие или системный сбой элемента СМК; или риск выпуска несоответствующей продукции покупателю | Нет оценки поставщиков; несколько СИ без поверки; отгрузка без приёмо-сдаточных испытаний |
| Незначительное несоответствие | Единичный сбой при работающем в целом процессе | Одна просроченная поверка; отсутствует подпись в одном протоколе |
| Наблюдение (область для улучшения) | Нарушения нет, но есть риск или возможность улучшения | Нечёткая формулировка в ТИ; тренд роста отклонений |

```
Требуемый элемент отсутствует или не работает?
├── Да → Системно (несколько случаев)? → Да → ЗНАЧИТЕЛЬНОЕ
│                                      → Нет → Может привести к поставке несоответствующей продукции? → Да → ЗНАЧИТЕЛЬНОЕ
│                                                                                                     → Нет → НЕЗНАЧИТЕЛЬНОЕ
└── Нет → Отклонение от процедуры? → Единичное → НЕЗНАЧИТЕЛЬНОЕ; Повторяющееся → ЗНАЧИТЕЛЬНОЕ
        → Есть возможность улучшения? → НАБЛЮДЕНИЕ
```

По каждому значительному несоответствию обязательно КД (навык `korrektiruyuschie-deystviya`), по незначительному — коррекция и КД по решению владельца процесса.

## 4. Отчёт по аудиту

Структура: цели и область; критерии; аудиторы и проверяемые; даты; резюме (3–5 строк: процесс результативен / частично / нет); сильные стороны; несоответствия (таблица: №, пункт, описание, категория, срок КД); наблюдения; выводы и рекомендации; рассылка. Оформлять в docx или документе.

## 5. Подготовка к внешнему аудиту

За 2–3 месяца до сертификационного/надзорного аудита или аудита покупателя:

- [ ] Программа внутренних аудитов выполнена, все пункты стандарта охвачены.
- [ ] Анализ СМК руководством проведён, протокол с решениями есть (п. 9.3).
- [ ] Все КД по прошлому внешнему аудиту закрыты, результативность подтверждена.
- [ ] Цели в области качества измеримы, есть данные по выполнению.
- [ ] Реестр рисков и возможностей актуален (п. 6.1).
- [ ] Оценка поставщиков проведена (п. 8.4).
- [ ] СИ поверены, график поверки выполняется.
- [ ] Обучение и компетентность персонала подтверждены записями.
- [ ] Проведён «пробный» аудит по самым рискованным процессам.

## Ошибки, которых избегать

- Проверять только документы, не выходя в цех.
- Писать находки без конкретного свидетельства (номер, дата, место).
- Формулировать несоответствие как рекомендацию («рекомендуется усилить») или как вину человека.
- Ставить «наблюдение», чтобы не портить отношения: системный сбой должен быть значительным несоответствием.
- Проводить аудит в формате «галочки» перед внешней проверкой.
