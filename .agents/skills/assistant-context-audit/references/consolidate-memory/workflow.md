# Сведение записей контекста
Открой явно выбранный журнал проекта, экспорт памяти или список правил. Пометь каждый элемент как долговременный, временный, дублирующий, конфликтующий или устаревший. Сохрани дату и источник при объединении. Относительные даты пересчитай в абсолютные при известной точке отсчёта. Для конфликтов покажи варианты с источниками. Удаление или изменение сохранённого контекста выполняй в пределах запроса. Обнови оглавление и проверь ссылки.
