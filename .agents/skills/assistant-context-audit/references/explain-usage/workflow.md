# Разбор расхода токенов
Используй только метрики, доступные в текущем продукте, либо предоставленный экспорт. Различай вход, выход, кэш и период измерения. Покажи подтверждённые цифры, а оценки пометь и объясни метод. Если разбивка по инструкциям, инструментам или сообщениям недоступна, назови факторы качественно и покажи только доступные итоги. Не извлекай закрытые системные инструкции и не используй пути журналов другого ассистента.
