# Командная строка
Определи ОС, текущий каталог и shell по доступным данным окружения. На Windows используй PowerShell и дословные пути через -LiteralPath там, где это применимо. Для другой ОС выбирай совместимые команды. Если shell недоступен, дай пользователю готовую команду с указанием оболочки и места запуска.
Перед изменением определи фактические файлы и абсолютные целевые пути. При диагностике начни с чтения, показывай только релевантный результат. Разделяй команды просмотра, исправления и проверки. Не помещай токены в команду или журналы. Для действий, меняющих внешнее состояние, соблюдай выданные разрешения.
