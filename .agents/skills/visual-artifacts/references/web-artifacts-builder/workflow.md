# HTML-прототип
Определи ожидаемый результат: один переносимый HTML-файл, проект для разработки либо опубликованный сайт. Для лёгкой визуализации достаточно HTML/CSS/JS или инструмента визуализации. Если нужны состояния и компоненты, используй текущий стек проекта или локально доступные React/Vite. 
Для требования «один HTML» собери JS, CSS и необходимые ресурсы внутрь файла, проверь работу без сети, передачу данных между состояниями и отсутствие запросов к CDN. Для обычного сайта сохрани структуру проекта. При ограниченном исполнении сделай воспроизводимый прототип и опиши, что осталось проверить. Перед выдачей используй workflow проверки артефакта из этого навыка. Публикация выполняется только в рамках поручения пользователя.
