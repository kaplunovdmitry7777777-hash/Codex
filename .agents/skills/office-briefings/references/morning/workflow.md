# Утренняя сводка руководителя
По запросу собери фактическую сводку из доступных календаря, почты, чатов и списка задач либо из загруженных выгрузок. Уточни местную дату и часовой пояс, если они не определены. По календарю укажи часы, подготовку и конфликтующие встречи. Отдели обязательства на сегодня, ожидаемые ответы, риски и пункт на завтра.
Отбирай по влиянию, сроку и возможности повлиять сегодня. Для ключевых строк дай источник, время и следующее действие. Укажи недоступные источники. Не считай молчание источника доказательством отсутствия дел. По запросу оформляй в Markdown, документе или локальном HTML; проверяй ссылки и отображение.
Для регулярного запуска используй доступную автоматизацию только когда пользователь попросил расписание. Зафиксируй источники, зону, дни и формат, без действий сверх согласованного объёма.
