## Правила форматирования

1. **Суммы**: `43 тыс ₽` для тысяч, `1,2 млн ₽` для миллионов. Без лишних копеек.
   Разряды разделять пробелом: `840 000 ₽`.
2. **Проценты**: один знак для трендов (напр. «▲ 8,3%»), целые в остальном.
3. **Даты**: по-человечески в тексте («14 апр»), ISO в метаданных («2026-04-14»).
4. **Отступ у стрелки**: `▲ 2 тыс ₽`, не `▲2 тыс ₽`.
5. **Длина**: цель — одна страница. Максимум две. Если секция разрослась — ужмите текст.
