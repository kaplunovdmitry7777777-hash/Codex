# Грабли

Известные режимы отказа навыка business-pulse. Пары «плохо / хорошо».

---

## Грабля: нужного файла нет в папке

**Почему важно:** если банковской выписки или выгрузки продаж в рабочей папке нет,
молчаливый пропуск секции «Касса» заставит владельца думать, что у него вообще нет
данных, — хотя он просто ещё не положил файл.

### ✗ Плохо

```
ассистент: [в папке нет выписки]
        → молча пропускает секцию «Касса»
        → сводка без денег; владелец думает, что что-то сломалось
```

### ✓ Хорошо

```
ассистент: [в папке нет выписки]
        → заголовок «Касса» на месте: «н/д — нет выгрузки выписки в папке»
        → в приложении: «Источники недоступны: банковская выписка — файла нет»
```

Владелец видит пробел явно и решает, выгрузить файл или работать с частичной сводкой.

## Грабля: Gmail отвалился по авторизации посреди сводки

**Почему важно:** авторизация Gmail иногда флапает. Показ сырой ошибки посреди
сводки выглядит как поломка и убивает доверие к навыку.

### ✗ Плохо

```
ассистент: [ошибка авторизации Gmail посреди сборки]
        → «Ошибка: авторизация Gmail не удалась. Переподключитесь.»
        → вывод обрывается или показывает сырую ошибку в секции «Что горит»
```

### ✓ Хорошо

```
ассистент: [ошибка авторизации Gmail]
        → продолжает сводку без секции «Что горит»
        → приложение: «Gmail — ошибка авторизации; „Что горит“ недоступно в этот раз»
        → остальные секции не затронуты
```

Сводка всё равно приносит пользу. Владелец информирован, а не напуган.

## Грабля: спрашивать разрешение перед сбором данных

**Почему важно:** ценность навыка — делать работу без лишних вопросов. Владелец,
который вызвал сводку, уже неявно согласился на чтение данных. Вопрос «проверить
выписку?» убивает смысл и подрывает доверие к навыку как к автономному помощнику.

### ✗ Плохо

```
Владелец: «введи меня в курс по бизнесу»
ассистент: «Проверить выписку для остатка? И можно посмотреть воронку Битрикс24?»
```

Три лишних круга до первой пользы.

### ✓ Хорошо

```
Владелец: «введи меня в курс по бизнесу»
ассистент: [сразу запускает все параллельные чтения/вызовы]
        → выдаёт сводку одним ответом
```

## Грабля: отправка в Telegram требует явного подтверждения

**Почему важно:** отправка в Telegram уходит туда, где её видят другие люди.
Автоотправка без подтверждения может подставить владельца или спамить чат.

### ✗ Плохо

```
ассистент: [в конце сводки]
        «Я отправил это в рабочий чат.»
```

Владелец не просил — а теперь финансовые данные видит вся команда.

### ✓ Хорошо

```
ассистент: [в конце сводки]
        «Отправить это в Telegram? Если да — в какой чат?»
```

Отправка происходит только при явном «да + название чата». Никогда не додумывайте.
