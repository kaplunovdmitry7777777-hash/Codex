# Реестр решений и поручений ГД

Вести двухуровневый реестр:

- **Уровень 1 — материалы обсуждения:** протоколы, стенограммы, расчёты, мнения служб, включая отклонённые аргументы. Не подгружать в новые обсуждения без прямой просьбы.
- **Уровень 2 — утверждённые решения:** только то, что утвердил ГД: решение, ответственный, срок, обоснование, отклонённые варианты, поручения. Именно этот уровень используется при подготовке следующих совещаний.

Разделение нужно, чтобы мнения из прошлых споров не выдавались за принятые решения.

## Где хранить

В рабочей папке пользователя (спросить один раз, если не указано):

```
Решения/
├── Материалы/ГГГГ-ММ-ДД-<тема>.md     # уровень 1
├── Решения/ГГГГ-ММ-ДД-<тема>.md       # уровень 2, одна запись на решение
├── Реестр_решений.md                   # индекс уровня 2, только дописывается
└── Реестр_поручений.xlsx (или .csv)    # таблица для контроля сроков
```

Колонки реестра поручений: №; Дата; Источник; Поручение; Ответственный; Срок; Статус (в работе / исполнено / перенесено / отменено); Дата исполнения; Переносов.

## Формат записи решения

```markdown
## [ДД.ММ.ГГГГ] — [Тема]

**Решение:** [одно ясное утверждение]
**Ответственный:** [одна должность/ФИО]
**Срок:** [ДД.ММ.ГГГГ]
**Контроль:** [ДД.ММ.ГГГГ — когда проверить результат]
**Обоснование:** [почему этот вариант, 1–2 предложения]

**Изменение ГД:** [если ГД изменил предложенный вариант — что и почему; иначе пусто]

**Отклонено:**
- [вариант] — [причина] [НЕ ВОЗВРАЩАТЬСЯ]

**Поручения:**
- [ ] [действие] — Отв.: [ФИО] — Срок: [дата] — Контроль: [дата]

**Заменяет решение от:** [дата, если есть]
**Заменено решением от:** [заполняется позже]
**Материалы:** Решения/Материалы/[дата]-<тема>.md
```

### Правила полей

| Поле | Правило |
|---|---|
| Решение | Одно утверждение. Если нужно два предложения — это два решения |
| Ответственный | Один человек. «Все» — значит никто |
| Срок | Обязателен. Нет срока — ставить 14 дней и контроль |
| Контроль | Всегда после срока, обычно через 2–4 недели |
| Обоснование | Обязательно. «Так решили» не обоснование |
| Изменение ГД | Записывать честно, не смягчать |
| Отклонено | Каждый отклонённый вариант с пометкой НЕ ВОЗВРАЩАТЬСЯ |

Исполненные поручения не удалять: `- [x] … — Исполнено: [дата] — Результат: [одно предложение]`. История и есть реестр.

## Порядок работы

### Фиксация решений после совещания

1. Взять протокол/заметки/расшифровку. Выделить решения, поручения, отклонённые варианты.
2. Каждое поручение проверить по правилу: глагол действия + измеримый результат + один ответственный + срок. Расплывчатые формулировки («усилить контроль», «обратить внимание») переписать и показать ГД на утверждение.
3. **Проверка противоречий** до записи:
   - новое решение совпадает с вариантом, ранее отклонённым с пометкой НЕ ВОЗВРАЩАТЬСЯ;
   - два действующих решения по одной теме противоречат друг другу;
   - одно и то же действие поручено разным людям.
   При конфликте вывести:
   ```
   ⚠️ КОНФЛИКТ РЕШЕНИЙ
   Новое: [текст]
   Противоречит: [дата] — [текст]
   Варианты: (1) заменить прежнее (2) объединить (3) вынести на решение ГД
   ```
   Для отклонённого ранее варианта: `🚫 Вариант «…» отклонён [дата], причина: … Для повторного рассмотрения ГД должен прямо сказать «пересмотреть [тема] от [дата]» с новыми фактами.`
4. Показать ГД итоговый список на подтверждение. Записывать в уровень 2 только после подтверждения.
5. Обновить индекс и таблицу поручений.

### Контроль исполнения

Запустить `python3 scripts/kontrol_porucheniy.py --input Реестр_поручений.csv [--na-datu ДД.ММ.ГГГГ] [--otvetstvennyy …] [--poisk …]` (путь относительно папки навыка). Скрипт выдаёт просроченные поручения, ближайшие сроки, поручения без срока и исполнительскую дисциплину по ответственным.

Сообщать без запроса:
- поручение перенесено 2 и более раз;
- у ответственного больше 3 просроченных поручений;
- один и тот же вопрос третий раз возвращается на совещание без решения;
- решение не исполнено к дате контроля.

### Поиск по реестру

На вопрос «что мы решили по X» искать только в уровне 2, давать дату, формулировку и статус поручений. Материалы уровня 1 поднимать только по прямой просьбе.
