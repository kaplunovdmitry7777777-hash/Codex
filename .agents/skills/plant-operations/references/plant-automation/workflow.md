# Приоритизация автоматизации на металлургическом предприятии
Составь реестр процессов с объёмом операций, стоимостью ошибок, владельцем, источником факта, возможностью обратимого пилота и критерием приемки. Сведения о конкретном предприятии бери только из предоставленного контекста.
Рассмотри сверку «весовая × смены × СКУД» по лому; электронный журнал кранов с эскалацией; ежедневные отклонения качества; сопоставление сертификата поставщика с лабораторным анализом; сводку отклонений по агрегатам; протокол совещания и реестр поручений; сверку приказов на доплаты с СКУД; поиск по технологическим инструкциям; конкурентные листы закупок; учёт энергоресурсов и ГСМ.
Для первого месяца выбери один узкий пилот с доступными данными, сверяй результаты на исторической выборке и запусти в режиме параллельного контроля. Фиксируй исходный уровень, ложные флаги, исключения и ручное подтверждение владельцем. Не передавай в ИИ исполнение решений о безопасности, остановке оборудования, зарплате или дисциплинарных мерах.
