# Загрузка мощностей, OEE и узкое место

Действовать как директор по производству / начальник ПЭО. Отвечать на три вопроса арифметикой, а не мнением:

1. Сколько тонн теряет каждый агрегат и на чём (простои, темп, брак)?
2. Выполним ли план следующего периода на фактической эффективности оборудования?
3. Какой агрегат ограничивает выпуск всей цепочки?

## Когда применять

- Формирование месячного/квартального/годового производственного плана и бюджета.
- Отдел продаж приносит дополнительный объём: нужно понять, есть ли под него мощность.
- План срывается, нужно отличить проблему мощности от проблемы организации (ожидание металла, валков, энергии).
- Обоснование инвестпроекта или графика ППР.

## Исходные данные

По каждому агрегату за отчётный период (обычно месяц): Агрегат; Передел; Календарное время, ч; Плановые простои, ч (ППР, капремонт, плановые перевалки); Внеплановые простои, ч; Номинальная производительность, т/ч; Выпуск, т; Брак, т; План след. периода, т; Время след. периода, ч.

Источники: суточные рапорты, журнал простоев (АСУ ТП / MES), сводки ПЭО, план производства. План по агрегатам пересчитывать через расходные коэффициенты: на 1 т проката нужна не 1 т заготовки.

## Порядок работы

1. Запустить `python3 scripts/oee_moschnosti.py --input <файл> --out oee.md` (путь относительно папки навыка). Скрипт считает доступность, производительность, качество, OEE, потери в тоннах, эффективную мощность и загрузку.
2. **Проверить «голодание».** Низкая производительность агрегата, стоящего ниже по цепочке (УПК, МНЛЗ после ДСП), часто означает ожидание металла, а не собственные потери. Такие тонны не списывать на агрегат; уточнить по журналу простоев.
3. **Узкое место** — агрегат с максимальной загрузкой. По теории ограничений Голдратта:
   - не допускать простоев узкого места (ремонтные бригады, запчасти, валки в первую очередь для него);
   - перенести с него всё, что можно сделать на других агрегатах;
   - ППР смежных агрегатов совмещать с ППР узкого места;
   - вкладываться в повышение мощности только узкого места, остальные инвестиции выпуска не добавят.
4. **Структура внеплановых простоев.** Если есть журнал простоев, построить Парето по причинам (механика, электрика, технология, ожидание, внешние). 20 % причин обычно дают 80 % часов.
5. **Численность.** Для расчёта людей на агрегат: явочная численность = посты × смены в сутки; списочная = явочная × коэффициент подмены. Коэффициент подмены = 1 / (1 − доля невыходов: отпуск, болезнь, обучение, гособязанности), для непрерывного 4-бригадного графика обычно 1,12–1,20. Отдельно учитывать текучесть: при 15 % в год на бригаду из 40 человек нужно нанять около 6 человек сверх прироста.
6. Свести вывод (см. «Формат вывода»).

## Ориентиры

| Показатель | Ориентир | Комментарий |
|---|---|---|
| OEE | 75–85 % хорошо, < 65 % резерв велик | Сравнивать агрегат с самим собой во времени, а не с «мировым уровнем» |
| Загрузка под план | ≤ 85 % | Выше 85 % любой внеплановый простой срывает план; > 100 % план невыполним без мер |
| Доля внеплановых простоев | < 5 % календарного времени | Рост — сигнал к пересмотру системы ТОиР |

## Формат вывода

- Вывод в 3–5 строк: выполним ли план, узкое место, главные потери в тоннах и в деньгах (тонны × маржинальный доход на тонну, если он известен).
- Таблицы скрипта: OEE, потери, загрузка.
- Меры по узкому месту: что сделать, эффект в тоннах, ответственный, срок.
- Если план невыполним: дефицит в тоннах и варианты (сократить ППР, перенести объём, изменить сортамент, докупить заготовку).

## Контрольные вопросы

1. Узкое место подтверждено данными (загрузка, очередь металла перед агрегатом) или это мнение?
2. Номинальная производительность паспортная или достигнутая? Для расчёта брать достигнутую на стабильном сортаменте.
3. План по сортаменту учтён? Мелкий профиль даёт меньше тонн в час, чем крупный.
4. Какой резерв на непредвиденное заложен? Плана под 100 % загрузки не бывает.
5. Что делается в первые сутки при аварийной остановке узкого места?
6. Учтены ли отпуска и текучесть при расчёте численности?

## Ошибки, которых избегать

- Планировать по средней производительности без учёта сортамента и сезонности.
- Считать мощность по паспорту, игнорируя фактическую доступность.
- Повышать загрузку неузких агрегатов: растут запасы незавершёнки, выпуск не растёт.
- Нанимать людей «под пик» без расчёта, хватит ли оборудования.
