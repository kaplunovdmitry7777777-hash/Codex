## CodeBurn

В текущем контейнере установлен опубликованный npm-пакет `codeburn@0.9.27`
и зависимости из lock-файла. Использована проектная установка с
`--ignore-scripts --no-audit --no-fund`; сторонние install/postinstall hooks
не выполнялись. Пакет находится в игнорируемом `node_modules`, в Git хранятся
только манифест, lock-файл и небольшой wrapper.

Воспроизвести установку в новой среде:

```bash
python3 tools/codeburn.py install
```

Нужны npm и совместимый Node.js; опубликованный пакет 0.9.27 указывает
Node.js >=22.13.0. Текущая среда использует Node.js 24.

Команды:

```bash
python3 tools/codeburn.py version
python3 tools/codeburn.py doctor
python3 tools/codeburn.py today
python3 tools/codeburn.py week
```

Навык `codeburn-cost` использует эти команды. Wrapper допускает только
перечисленные операции, отключает автоматическую синхронизацию аккаунта Cursor
через `CODEBURN_CURSOR_SYNC=0`, задаёт `DO_NOT_TRACK=1`. Он не выполняет quota,
авторизацию, share/sync/devices, guard, установку desktop-приложения или изменения
настроек агента. Запрос справочника цен к публичному GitHub при расчётах возможен;
режим не объявляется полностью офлайн. Сам CodeBurn может сохранять локальные кеши.

Наличие CLI не означает наличие истории пользователя: эта среда не получает
диск Windows, все журналы других компьютеров или полный счёт Codex Cloud.
Без доступных журналов измерить расход нельзя. Стоимость по моделям может
быть расчётной и отличаться от счёта подписки.

Публикационный gitHead npm-пакета: `7ecc87f8adb2719482cf4a382605761102b34870`.
Он отличается от просмотренного текущего main CodeBurn
`d657b8886285f9257b4a71aea3afec15426d6201`; исходники main не выдаются за
побайтно совпадающий npm-артефакт. Целостность npm-пакета фиксируется в lock-файле.

## Что не установлено

Graphify не установлен из-за воспроизводимой проблемы чтения файлов в проверенном
Fortran-препроцессоре. Полный Caveman не установлен из-за ненужного для выбранного
сценария перехвата запросов и облачной маршрутизации. Переданный позже
`context-audit.zip` проверен отдельно и не включён в установку.

## Где доступны навыки

Файлы находятся в репозитории, рабочая ветка `codex/migrate-cloud-skills`.
После включения PR они будут в `main`. Для использования загрузчиком Codex
нужна новая задача с этой веткой. Установка зависимостей контейнера не является
глобальной установкой на компьютер пользователя или в настройки аккаунта.
Прямого инструмента импорта пользовательских навыков в настройки аккаунта
в этой сессии нет. Отдельный ZIP Caveman для ручного импорта можно скачать
из репозитория: `downloads/caveman-standalone-codex.zip`.

Результаты проверок сохранены в `migration/optional-tools-installation.json`
и `migration/optional-tools-discovery.json`.
